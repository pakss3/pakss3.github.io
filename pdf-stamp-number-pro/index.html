주요 기능 / Key Features

한국어

  • PDF 페이지 번호와 Bates numbering 지원: prefix, suffix, zero-padding 설정 가능
  • 텍스트 워터마크, 이미지 워터마크, 프리셋 스탬프, 날짜 스탬프, QR 코드 스탬프 제공
  • 여러 PDF를 한 번에 처리하는 배치 작업 지원
  • 페이지 범위, 홀수/짝수 페이지 위치, 출력 방식 등을 세밀하게 조정 가능
  • 내보내기 기록을 확인하고 다시 공유할 수 있는 히스토리 제공
  • 문서 처리는 기기 내에서 수행되며, 사용자가 직접 공유하지 않는 한 클라우드 업로드를 요구하지 않음

English

  • PDF page numbering and Bates numbering with prefix, suffix, and zero-padding controls
  • Text watermarks, image watermarks, preset stamps, date stamps, and QR code stamps
  • Batch processing for multiple PDFs in one workflow
  • Fine-grained controls for page range, odd or even placement, and export choices
  • Export history for quick review and re-sharing
  • Documents are processed on device unless the user intentionally shares the output

사용 사례 / Use Cases

한국어

  • 법률 문서에 Bates 번호와 기밀 표시 추가
  • 사내 승인용 문서에 DRAFT, APPROVED, REVIEWED 스탬프 적용
  • 교육용 PDF에 검토, 채점, 제출 상태 표시 추가
  • 배송, 물류, 사무 문서에 페이지 번호와 QR 코드 삽입

English

  • Add Bates numbers and confidentiality marks to legal PDFs
  • Apply DRAFT, APPROVED, and REVIEWED stamps to office documents
  • Mark educational PDFs with review, grading, and submission labels
  • Insert numbering and QR codes into logistics, shipping, and workflow documents
