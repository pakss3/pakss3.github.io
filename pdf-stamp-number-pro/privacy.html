1. 개요 / Overview

한국어

PDF Stamp Number Pro는 사용자가 선택한 PDF에 페이지 번호, Bates numbering, 워터마크, 스탬프, QR 코드를 적용하고 저장 또는 공유할 수 있도록 제공되는 앱입니다.

English

PDF Stamp Number Pro helps users apply page numbers, Bates numbering, watermarks, stamps, and QR codes to selected PDF files and then save or share the results.

2. 수집 및 처리 정보 / Information We Process

한국어

  • 앱은 회원가입 기능을 제공하지 않으며 이름, 이메일, 비밀번호를 직접 수집하지 않습니다.
  • 사용자가 선택한 PDF, 이미지, 텍스트 입력값은 편집 및 내보내기 목적의 기기 내 처리에 사용됩니다.
  • 앱 안정성 개선, 성능 분석, 광고 제공을 위해 일부 SDK가 기술 정보나 기기 식별자를 처리할 수 있습니다.

English

  • The app does not provide account sign-up and does not directly collect name, email, or password.
  • User-selected PDFs, images, and text inputs are used for on-device editing and export workflows.
  • Some SDKs may process technical information or device identifiers for app stability, analytics, and ads.

3. 권한 사용 / Permissions

한국어

  • 파일 또는 문서 접근 권한: 사용자가 PDF를 선택하거나 결과를 저장할 때 사용합니다.
  • 사진 라이브러리 접근 권한: 이미지 워터마크 선택 등 사용자가 요청한 기능에만 사용합니다.
  • 권한 설정은 기기 설정에서 언제든지 변경할 수 있습니다.

English

  • File or document access: used when the user selects PDFs or saves exported results.
  • Photo library access: used only for user-requested actions such as selecting image watermarks.
  • Permission choices can be changed at any time in device settings.

4. 기기 내 처리 / On-Device Processing

한국어

사용자가 선택한 문서와 이미지 데이터는 앱 기능 수행을 위해 기기 내에서 처리됩니다. 사용자가 직접 공유 또는 내보내기를 선택하지 않는 한, 앱은 이를 외부로 전송하기 위한 계정 기반 업로드를 요구하지 않습니다.

English

Selected documents and images are processed on the device to provide core features. The app does not require account-based cloud upload unless the user intentionally shares or exports content.

5. 제3자 서비스 / Third-Party Services

한국어

앱에는 광고 또는 분석 기능이 포함될 수 있으며, 관련 SDK 제공자가 서비스 제공에 필요한 정보를 처리할 수 있습니다. 해당 정보 처리는 각 제공자의 정책을 따릅니다.

English

The app may include advertising or analytics services. Related SDK providers may process information required to deliver those services, subject to each provider's own policy.

6. 보관 및 삭제 / Retention and Deletion

한국어

사용자가 생성한 결과물과 일부 작업 기록은 사용자의 기기 또는 사용자가 선택한 저장 위치에 남을 수 있습니다. 앱 삭제 또는 관련 데이터 삭제는 사용자 기기에서 직접 관리할 수 있습니다.

English

Exported files and some workflow history may remain on the user's device or selected storage location. Users can manage or remove this data directly from their device.
