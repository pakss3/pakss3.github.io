Official support Version 1.9.0 iPhone only

문제가 생기면 여기서 바로 확인하세요

Neon Blocks Daily 관련 문의, 오류, 광고 로딩, 진행 상황 저장 문제는 이 페이지를 기준으로 안내합니다. Starting with version 1.9.0, the app is intended for iPhone and is no longer presented as an iPad-supported experience.

지원 기기 / Supported devices

현재 공개 버전은 iPhone용으로 제공됩니다. iPad는 지원 대상에서 제외합니다. The current release is intended for iPhone.

광고 보상 / Rewarded ads

보상형 광고는 네트워크 상태와 광고 재고에 따라 로딩 시간이 달라질 수 있습니다. If a rewarded ad does not load immediately, please retry after a short moment.

진행 저장 / Save progress

게임 진행 데이터는 기본적으로 기기 로컬 저장소에 보관됩니다. Reinstalling the app or clearing app data can remove local progress.

자주 묻는 질문 / FAQ

  • 광고가 바로 나오지 않으면 네트워크 연결을 확인한 뒤 잠시 후 다시 시도해 주세요.
  • 하트는 일정 시간마다 자동으로 충전되며, 앱을 다시 열 때 남은 시간이 반영됩니다.
  • 진행 데이터는 주로 로컬에 저장되므로 앱 삭제 후 복구가 제한될 수 있습니다.
  • If you report a bug, please include your device model, iOS version, and a short reproduction path.

문의 전 확인해 주세요 / Before contacting support

  • 앱 버전과 사용 기기를 함께 알려 주세요.
  • 문제가 발생한 화면, 버튼 이름, 재현 순서를 짧게 적어 주세요.
  • 광고 관련 문제는 인터넷 연결 상태도 함께 알려 주시면 확인이 더 빨라집니다.
  • For ad or review issues, include whether the problem happened on Wi-Fi or mobile data.
