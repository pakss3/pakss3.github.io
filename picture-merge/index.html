주요 기능 / Key Features

한국어

  • 46개 템플릿 제공: 기본, 그리드, 분할, 스트립, 비율, A4 출력
  • 검색, 카테고리, 필터로 원하는 레이아웃을 빠르게 탐색
  • 드래그와 확대 중심의 직관적인 사진 배치 편집
  • JPG, PNG, PDF 고화질 내보내기와 즉시 공유 지원
  • 회원가입 없이 바로 사용 가능
  • 한국어와 영어 인터페이스 지원

English

  • 46 templates: basic, grid, split, strip, ratio, and A4 print layouts
  • Fast discovery with search, categories, and filter chips
  • Intuitive drag and zoom based photo placement
  • High-quality export to JPG, PNG, and PDF with quick sharing
  • No sign-up required
  • Korean and English interface support

English

  • Organize travel, family, and pet photos into one clean image
